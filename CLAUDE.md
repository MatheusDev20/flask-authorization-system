# Context

This is a small hobby Flask project the user built about four years ago (2022). They have not written Python since.

## Why we're here

The user has a job interview on **Monday 2026-05-18** that may require demonstrating Python skills. They are familiar with the language but rusty. This project is being used as a hands-on refresher to get back up to speed with Python and Flask.

## How to collaborate

- Treat this as a learning / re-familiarization exercise, not a production codebase.
- When making changes, briefly explain the Python/Flask idioms involved so the user re-internalizes them, rather than just producing finished code.
- Call out any patterns that are outdated or no longer idiomatic (the code is ~4 years old) so the user doesn't carry stale habits into the interview.
- Prefer small, comprehensible changes over sweeping refactors.
